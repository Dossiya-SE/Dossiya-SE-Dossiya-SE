# Control Theory

**ID:** `MATH-21` · **Prerequisites:** `MATH-06`, `MATH-13`, `MATH-15` · **Status:** `NOT_TESTED`

```math
\dot x=f(x,u,t),\qquad u=\pi(x,t).
```

Required topics: controllability, observability, feedback, optimal/robust control, constraints. A control law is not operationally implementable merely because it is mathematically feasible.
