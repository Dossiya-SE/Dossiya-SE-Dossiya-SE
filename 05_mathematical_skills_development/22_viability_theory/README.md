# Viability Theory

**ID:** `MATH-22` · **Prerequisites:** `MATH-13`, `MATH-15`, `MATH-21` · **Status:** `NOT_TESTED`

```math
\operatorname{Viab}_F(K)=\{x_0\in K:\exists u(\cdot),\;x(t)\in K\;\forall t\ge0\}.
```

State space, safe/acceptable set `K`, dynamics, controls, time horizon, uncertainty, and numerical approximation must be explicit. A viability kernel is not a generic resilience score.
