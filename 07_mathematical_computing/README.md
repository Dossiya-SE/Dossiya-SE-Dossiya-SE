# Mathematical computing language map

| Language/system | Primary role |
|---|---|
| Python | orchestration, symbolic/numeric work, testing, visualization |
| Julia | high-performance differential equations and scientific computing |
| Wolfram Language | symbolic differential geometry and exact manipulation |
| Asymptote | mathematically exact vector/3-D illustration |
| LaTeX/TikZ/PGFPlots | publication typography and vector diagrams |
| GLSL | GPU curvature/field rendering |
| C++/CUDA | future high-performance kernels |
| Rust | future reliable numerical infrastructure |
| JavaScript/Three.js | future interactive web geometry |
| Lean/Coq/Isabelle | future formal verification |

The V1 repository contains executable/reference implementations in the first six rows. Other languages enter only when they provide a measurable benefit; language count is not treated as scientific quality.
