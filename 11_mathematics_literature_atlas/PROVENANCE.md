# Provenance protocol

Every theorem/model/algorithm record should distinguish:

- original source;
- modern reference used for notation;
- derivation reproduced locally;
- computational implementation;
- known extensions;
- application literature.

The V1 references are intentionally minimal and canonical. The atlas is not yet a systematic review.

## Example lineage

`Gauss -> Riemann -> Christoffel -> Ricci/Levi-Civita -> modern Riemannian geometry`

For each future lineage, store exact bibliographic metadata and avoid attributing a modern formulation to an earlier author unless the historical source supports it.
