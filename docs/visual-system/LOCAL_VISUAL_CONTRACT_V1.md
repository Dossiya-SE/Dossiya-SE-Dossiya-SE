## Local rules

1. Mathematical/source status must survive visualization unchanged.
2. Canonical interface/highlight accent is the Light Sky Blue family:
   - RGB (135,206,250) / #87CEFA;
   - RGB (45,143,214) / #2D8FD6 for accessible geometry on light backgrounds;
   - RGB (191,232,255) / #BFE8FF for dark-surface accent text.
3. Gold, amber, ochre and yellow-gold are forbidden visual roles.
4. Every SVG must have a viewBox, non-empty title/desc and role="img".
5. Animation is supplementary. Static SVG remains scientific authority.
6. Motion variable `τ_ui` denotes reveal/presentation time only.
7. Module activation order does not encode importance, difficulty, duration or causality.
8. CI must fail closed on palette drift, SVG accessibility failure, missing motion provenance or nondeterministic animation output.
